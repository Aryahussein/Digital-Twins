.. _fault-analysis-module:

Fault Analysis Utilities
=======================

This module implements functions to rank component sensitivities, generate fault
tables (shorts & opens), compute resistance thresholds using large‑change
sensitivity formulas, and pretty‑print the results.  The routines operate on a
:class:`~core.results.SimulationResult` that already contains an
:class:`~core.results.SensitivityData` tensor.

-----------------------------------------------------------------------

.. py:function:: rank_component_sensitivities(result)

   Rank order component sensitivities from largest to smallest.

   Parameters
   ----------
   result : :class:`SimulationResult`

   Returns
   -------
   list[dict] | None

   Prints a table of the top ten sensitivities and returns the full sorted list.

-----------------------------------------------------------------------

.. py:function:: perform_global_ranking(circuit, result)

   Generate a fault table ranking both open and short faults for each output node
   using adjoint sensitivity data.

   Parameters
   ----------
   circuit : :class:`Circuit`
   result : :class:`SimulationResult`

   Returns
   -------
   dict | None

   The dictionary keys are output nodes; each value is a list of fault dictionaries
   sorted by absolute impact.  Each fault entry contains:

   * ``type`` – ``"Open"`` or ``"Short"``
   * ``location`` – component name or node pair
   * ``impact`` – peak magnitude of the sensitivity waveform
   * ``time`` – sweep step at which the impact occurs

-----------------------------------------------------------------------

.. py:function:: compute_fault_thresholds(circuit, result, output_node,
                                         delta_F, top_n=10, r_sweep_shorts=None,
                                         r_sweep_opens=None, dt=None, method='TR')

   Compute fault resistance thresholds using the large‑change sensitivity
   formula.  For each of the top faults returned by
   :func:`perform_global_ranking`, a sweep over short/open resistances is performed.
   The smallest/​largest resistance that drives the output change beyond
   ``delta_F`` volts is recorded.

   Parameters
   ----------
   circuit, result, output_node, delta_F
       As described above.
   top_n : int, optional – number of faults to process for each type.
   r_sweep_shorts, r_sweep_opens : np.ndarray, optional
       Resistance sweep arrays; defaults to a wide log‑space.
   dt : float, optional
       Time step (used for companion model conductances).
   method : str, optional
       Integration method ('TR' or 'BE').

   Returns
   -------
   dict

   The returned dictionary contains:

   * ``shorts`` – list of short fault threshold dictionaries.
   * ``opens``  – list of open fault threshold dictionaries.
   * ``domain`` – string indicating the analysis domain (time, frequency, etc.).

-----------------------------------------------------------------------

.. py:function:: print_fault_table(all_fault_tables, top_n=15)

   Pretty‑prints a ranking table for each output node.  Useful after
   :func:`perform_global_ranking`.

-----------------------------------------------------------------------

.. py:function:: print_threshold_table(threshold_results)

   Pretty‑prints the threshold tables generated by
   :func:`compute_fault_thresholds`.  It shows the worst short/open,
   voltage values, ΔV, and observation windows.

-----------------------------------------------------------------------

Example usage

.. code-block:: python

   from fault_analysis import perform_global_ranking, compute_fault_thresholds
   all_faults = perform_global_ranking(circuit, result)
   thresholds = compute_fault_thresholds(circuit, result, "out", delta_F=0.1)
   print_fault_table(all_faults)
   print_threshold_table(thresholds)
