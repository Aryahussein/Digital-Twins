* 3-Stage CMOS Ring Oscillator
* Nodes: VDD (1), GND (0), Stage1 (n1), Stage2 (n2), Stage3 (n3)

* Power Supply (1.8V)
VDD 1 0 1.8

* Stage 1: n3 -> n1
M1_P n1 n3 1 1 PMOS W=2u L=0.18u
M1_N n1 n3 0 0 NMOS W=1u L=0.18u
C1 n1 0 100f

* Stage 2: n1 -> n2
M2_P n2 n1 1 1 PMOS W=2u L=0.18u
M2_N n2 n1 0 0 NMOS W=1u L=0.18u
C2 n2 0 100f

* Stage 3: n2 -> n3
M3_P n3 n2 1 1 PMOS W=2u L=0.18u
M3_N n3 n2 0 0 NMOS W=1u L=0.18u
C3 n3 0 100f

.MODEL NMOS NMOS (LEVEL=1 VTO=0.4 KP=170u GAMMA=0.5 LAMBDA=0.1 PHI=0.7)
.MODEL PMOS PMOS (LEVEL=1 VTO=-0.4 KP=50u GAMMA=0.5 LAMBDA=0.1 PHI=0.7)

* The Kickstart: Force node n1 to 0V at t=0
.IC V(n1)=0

* Analyses
.TRAN 10p 5n
.OP
