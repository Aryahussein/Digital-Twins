* ====================================================================
* STATISTICAL CMOS INVERTER NETLIST
* ====================================================================

* 1. THE POWER SUPPLY
* Using AGAUSS (Absolute Gauss): 1.8V nominal, +/- 36mV at 3-sigma (2% tolerance)
V_VDD VDD 0 AGAUSS(1.8, 0.036, 3)

* 2. THE INPUT SIGNAL (Perfectly ideal, no statistical variance)
V_IN IN 0 PULSE(0 1.8 1n 10p 10p 2n 4n)

* 3. GLOBAL PROCESS CORNERS
* Using GAUSS (Relative Gauss): +/- 5% variance on VTO, 10% on KP at 3-sigma
.MODEL NMOS_MOD NMOS (VTO=GAUSS(0.7, 0.05, 3) KP=GAUSS(120u, 0.10, 3))
.MODEL PMOS_MOD PMOS (VTO=GAUSS(-0.7, 0.05, 3) KP=GAUSS(40u, 0.10, 3))

* 4. LOCAL DEVICE MISMATCH
* Assume manufacturing causes local 2% fluctuations
M_N OUT IN 0 0 NMOS_MOD W=GAUSS(2u, 0.02, 3) L=0.18u
M_P OUT IN VDD VDD PMOS_MOD W=GAUSS(4u, 0.02, 3) L=0.18u

* 5. THE LOAD
C_LOAD OUT 0 UNIF(10f, 0.10)

.TRAN 0.01n 10n
.END
