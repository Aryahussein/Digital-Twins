Circuit Representation Module¶

This module provides the central Circuit class, which acts as the primary data structure for the simulator. It includes the factory logic to instantiate polymorphic components from parsed netlist dictionaries and generates the Modified Nodal Analysis (MNA) matrix indexing scheme.

Factory Helper¶

create_component(name, data_dict)¶

Instantiates the correct Component subclass based on the netlist type.

Parameters:

  • name (str) – The unique netlist name of the component (e.g., 'R1' or 'M_MAIN').

  • data_dict (dict) – The parsed parameter dictionary containing at minimum a 'type' key (e.g. {'type': 'R', 'n1': '1', 'n2': '0', 'value': 1000}).

Returns:

An instantiated component object.

Return type:

Component

Raises:

  • KeyError – If the 'type' key is missing.

  • ValueError – If the component type is not recognized.

Circuit Class¶

class Circuit(parsed_components)¶

Represents the physical circuit, containing components and matrix topology.

components¶

A list of instantiated polymorphic component objects.

components_dict¶

A name‑to‑object lookup dictionary for fast access.

node_map¶

Maps node names (and MNA branch names) to integer matrix indices.

total_dim¶

The total dimension of the MNA matrix (N × N).

get_idx(node)¶

Retrieves the matrix row/column index for a given node.

Parameters:

node – Ground nodes (0, "0", or "GND") return None.

Returns:

Integer index or None.

_build_node_index()¶

Scans components to build the MNA matrix coordinate map.

get_component(name)¶

Retrieves a component object by its netlist name.

Parameters:

name (str) – The component’s netlist identifier.

Raises:

KeyError – If the component is not found.

differentiable_params¶

A master list of all tunable parameters in the circuit. It aggregates differentiable_params from each individual component, ensuring no duplicates.
