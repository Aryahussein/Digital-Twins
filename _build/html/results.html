Simulation Result & Sensitivity Data¶

This module provides two high‑level containers that are returned by the simulator: ```

  • SensitivityData – A unified 3‑D tensor for all sensitivity results.

  • SimulationResult – The “vault” that stores raw simulation outputs and, when available, the associated sensitivities.

class SensitivityData(sweep_axis, param_names, output_nodes, domain='static')¶

Holds a 3‑D tensor of shape (Parameters × Output Nodes × Sweep Steps). The class offers convenient query helpers that hide the raw NumPy indexing from the user.

sweep_axis¶

numpy.ndarray – Independent variable array (time, frequency, voltage, or single value for .OP).

domain¶

Physical domain of the sweep (“time”, “frequency”, “voltage”, “static”).

param_names¶

Ordered list of parameter names (axis‑0 labels).

output_nodes¶

Ordered list of output node names (axis‑1 labels).

data¶

numpy.ndarray – The underlying 3‑D sensitivity tensor.

param_index¶
output_index¶

Dictionaries mapping names → indices for fast lookup.

get_sweep_series(param, output_node)¶

Returns the 1‑D array of partial derivatives ∂output/∂param across the sweep axis.

Parameters:

  • param (str) – Parameter name.

  • output_node (str|int) – Target node.

Returns:

numpy.ndarray – 1‑D sensitivity series.

get_matrix_at_step(step_idx)¶

Returns a 2‑D matrix (n_params × n_outputs) at the given sweep index.

Parameters:

step_idx (int) – Sweep index.

Returns:

numpy.ndarray.

print_matrix_at_step(step_idx, output_node, sens_parameter)¶

Nicely formatted console output of the sensitivity matrix for a single sweep step. Useful for quick debugging or CLI reporting.

class SimulationResult(analysis_type, sweep_axis, VI_matrix, node_map)¶

A container that holds all information produced by a simulation run:

  • The raw solution matrix (VI).

  • The node/branch mapping.

  • Optional sensitivities (an instance of SensitivityData).

type¶

Analysis type string (‘.TRAN’, ‘.AC’, ‘.DC’, ‘.OP’).

sweep_axis¶

Independent variable array.

VI¶

Raw solver output matrix (2‑D for sweeps, 1‑D for .OP).

node_map¶

Mapping of node/branch names → column indices in VI.

sensitivities¶

Optional SensitivityData instance.

get_vhats(node)¶

Retrieves the raw adjoint vector history (useful for fault analysis).

_resolve_node_key(node)¶

Internal helper that normalises user‑supplied node identifiers to the exact key stored in node_map.

get_voltage(node)¶

Returns the voltage or branch current array for node. Handles complex values for .AC, real values otherwise.

get_sensitivity_parameters(node)¶

List of parameters that have sensitivity data for node. Useful for populating UI dropdowns.

get_sensitivity(node, param)¶

Returns the sensitivity gradient for a given output node and parameter. For single‑point analyses it returns a scalar; otherwise a 1‑D array across the sweep axis.
