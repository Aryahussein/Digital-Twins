Diode & NMOS Level‑1 Models¶

This module implements two small‑signal models that are useful in SPICE‑style circuit simulation:

  • evaluate_diode() – Shockley diode model with sensitivity to the saturation current.

  • evaluate_nmos() – Level 1 MOSFET (NMOS) model including gradients for V<sub>TO</sub> and β<sub>n</sub>.

The functions return dictionaries containing the large‑signal quantities as well as the required small‑signal conductances and sensitivity gradients.

evaluate_diode(vd, Is, Vt)¶

Evaluates the Shockley diode model.

Parameters:

  • vd (float) – Voltage across the diode (Anode – Cathode).

  • Is (float) – Saturation current (e.g., 1e‑14 A).

  • Vt (float) – Thermal voltage (e.g., 0.02585 V).

Returns:

dict with keys:

  • "I_D" – Large‑signal current in amperes.

  • "gd" – Small‑signal conductance dI/dv (siemens).

  • "dId_dIs" – Sensitivity gradient ∂I/∂Is.

Return type:

dict

evaluate_nmos(vgs, vds, VTO, Bn)¶

Evaluates the Level 1 NMOS model with sensitivity gradients.

Parameters:

  • vgs (float) – Gate‑source voltage.

  • vds (float) – Drain‑source voltage.

  • VTO (float) – Threshold voltage (V<sub>TO</sub>).

  • Bn (float) – Transconductance parameter β<sub>n</sub> = μₙC<sub>ox</sub>(W/L).

Returns:

dict with keys:

  • "I_D" – Drain current (A).

  • "gm" – Transconductance dI/dV<sub>GS</sub>.

  • "gds" – Output conductance dI/dV<sub>DS</sub>.

  • "dId_dBn" – Sensitivity ∂I/∂β<sub>n</sub>.

  • "dId_dVTO" – Sensitivity ∂I/∂V<sub>TO</sub>.

Return type:

dict
